Poné acá una imagen de fondo (PNG o JPG) de 900x600 para cada escena.
El nombre del archivo tiene que ser exactamente el nombre de la escena:

  inicio.png   -> selva
  cueva.png    -> cueva
  mono.png     -> cueva (con el mono) - podés reusar la misma que cueva.png
  cofre.png    -> susto / cueva en penumbra
  tesoro.png   -> brillo dorado / final feliz
  rio.png      -> orilla del río
  aldea.png    -> aldea

Si falta el archivo de una escena, el juego usa el color de fondo de
respaldo definido en FONDOS dentro de aventura.py, así que no hace
falta tener todas las imágenes para poder probar el juego.

Podés usar .jpg en vez de .png, aventura.py prueba ambas extensiones.
