# Requisitos comunes a todas las opciones

- **Pantalla de inicio** con al menos un botón "Comenzar Juego".
- **Game Over** al perder, con opción de volver al menú.
- **Victoria** al completar el objetivo, con opción de volver al menú.
- **Motor:** se puede usar el del curso (o alternativa previa consulta al docente); si se usa, se puede modificar/extender **documentando los cambios** → [[cambios-al-motor]].
- **Sonido** en toda interacción con botones y componentes de UI. → [[audio]]
- **README** del repo: instalar y ejecutar paso a paso. → [[readme-plantilla]]
- **Video** de 15–40 s mostrando el juego y sus funcionalidades. → [[video-guion]], [[recorder]]
- Python + Pygame obligatorio.
